Audio cleanup

Background noise

Start with Natural sound. Preview up to 10 seconds from the playhead before exporting. The noise sample ignores cuts, volume regions and visual edits.

Speech volume and fades

Gently compress loud speech and add up to 6 dB of gain. This is not a loudness target or a fix for every quiet phrase.

Fades apply at the beginning and end of the final output. Each is limited to half its length. Use Preview result to hear all audio settings together.

This file has no audio track.

Mute and volume regions

Adjust a passage in the selected sound mix, including presenter audio. Source playback stays original; use Hear edited audio to check the result. Regions apply to the selected mix, including presenter audio.

Short fades ease in and out of each region. Overlapping volumes multiply, with total gain capped at 200%; mute wins. Boosts use a limiter to avoid clipping.

Storage and cleanup

Files are processed by the computer running FreeEdit. If you opened a hosted instance, that computer is its server.

Temporary files expire automatically. Active processing is protected.

Your original file stays unchanged. Use Save project to keep edits for another day, and keep the original recording. Browser recovery stores your latest session on this browser only. Starting another file discards that recovery.

Open this dialog to check disk usage.

Cleanup removes only inactive recordings belonging to this browser session. Other visitors' recordings and active processing are not affected. Download anything you need first.

About FreeEdit

A focused, open-source utility for cleaning up audio and video recordings.

Noise reduction uses DeepFilterNet3. Media analysis and export use FFmpeg.

No account required. For setup, source code, and known limitations, visit the GitHub repository.
