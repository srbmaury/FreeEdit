Storage and cleanup

Files are processed by the computer running FreeEdit. If you opened a hosted instance, that computer is its server.

Temporary files expire automatically. Active processing is protected.

Your original file stays unchanged. Use Save project to keep edits for another day, and keep the original recording. Browser recovery stores your latest session on this browser only. Starting another file discards that recovery.

Open this dialog to check disk usage.

Cleanup removes other inactive recordings and their exports on this server, including other browser sessions. Your open recording and active processing are kept. Download anything you need first.

About FreeEdit

A focused, open-source utility for cleaning up audio and video recordings.

Noise reduction uses DeepFilterNet3. Media analysis and export use FFmpeg.

No account required. For setup, source code, and known limitations, visit the GitHub repository.
