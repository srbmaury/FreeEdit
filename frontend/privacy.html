Privacy Policy

This policy covers the hosted FreeEdit editor at freeedit.srbmaury.com and the FreeEdit ChatGPT plugin. If you run FreeEdit on your own infrastructure, your installation determines where its files are processed and stored.

Data FreeEdit processes

  • Editor uploads and edits. The hosted editor receives the video, audio, images, and other assets you submit, along with filenames and editing settings. FreeEdit uses these inputs to create previews, process edits, and deliver exports. Media may contain personal information, including voices or faces.
  • Narration. When you use the editor or ask ChatGPT to run FreeEdit’s narration tool, FreeEdit receives the text to read and the applicable voice and speed settings. Kokoro processes this text on the FreeEdit server. The plugin returns an expiring WAV download link to ChatGPT. OpenAI handles your conversation and the tool result under its own policies.
  • Session and service data. The editor uses a signed random session cookie to keep temporary jobs associated with the browser session that created them. FreeEdit uses request metadata and connection information for service security, rate limits, error diagnosis, and reliability. Infrastructure providers may also process IP addresses, timestamps, and request information.
  • Browser storage. The editor can store preferences and project recovery data, including local media or references to media where supported, in your browser. FreeEdit does not require a website account for editing.

Storage and retention

The hosted editor is configured to clean up temporary jobs after about one hour without a job update. Active uploads and processing jobs are excluded until they finish. This cleanup covers the server’s job files, including hosted uploads and rendered outputs. Save your project and download anything you need before leaving.

FreeEdit does not save narration scripts as project files. The website returns generated narration directly. For ChatGPT, FreeEdit holds the WAV in server memory. The link expires after ten minutes or when the server restarts, whichever comes first. Expired entries are removed when the narration cache is next accessed. Anyone with the link can download the audio while it is valid.

The session cookie lasts up to seven days. Browser recovery data and preferences can remain until cleared. Downloaded files remain wherever you saved them. Operational and infrastructure logs are separate from temporary jobs and are subject to the applicable logging settings and provider retention.

Who receives data

FreeEdit uses hosting and network infrastructure to deliver and protect the service. These providers may process requests and hosted content as needed to operate their services. OpenAI is involved when you use the ChatGPT plugin. FreeEdit runs its narration model on its server and does not send scripts to an external text-to-speech API. FreeEdit may disclose data when legally required.

Your controls and privacy requests

Use the editor’s storage cleanup controls to remove eligible temporary jobs in your session. Clear site data in your browser to remove local preferences, recovery data, and the session cookie. Manage ChatGPT conversations and plugin access in ChatGPT. Removing a website job or clearing browser data does not delete copies held by ChatGPT or files you already downloaded.

For privacy questions or requests, use the contact link on the FreeEdit publisher’s website. Please avoid posting private recordings, scripts, download links, or identifiers in public GitHub issues.
